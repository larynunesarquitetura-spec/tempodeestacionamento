
# 🚗 Digital Parking Meter

A simple and interactive parking meter simulator developed with JavaScript.

This project was created to practice Object-Oriented Programming (OOP), DOM manipulation, and business logic using JavaScript.

## 💻 About the Project

The Digital Parking Meter allows users to enter a payment amount and automatically calculates the corresponding parking time and change.

If the payment amount is less than R$1.00, the application displays an insufficient payment message.

## ✨ Features

- Payment amount input
- Automatic parking time calculation
- Change calculation
- Insufficient payment validation
- Interactive user interface
- Responsive design

## 🛠️ Technologies

- HTML5
- CSS3
- JavaScript
- Object-Oriented Programming (OOP)
- DOM Manipulation

## 🚀 How to Run

1. Clone this repository.
2. Open the project folder.
3. Open `index.html` in your browser.
4. Enter a payment amount.
5. Click the calculate button.
